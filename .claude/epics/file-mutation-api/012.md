# Task: Integration tests + raise branch coverage gate to 80%

## Description

End-to-end coverage of the HTTP surface, then raise the coverage gate from its bootstrap
threshold to the real 80%.

Split from the original testing task because writing tests and building the CI gate are
different work, and because the gate must exist from the first merge (it is scaffolded in
001 at threshold 0) rather than arriving halfway through the epic.

## Context for the implementer

The gate already exists in CI from task 001 — this task **raises its threshold**, it does not
build it. Check `.github/workflows/ci.yml` for the current wiring before adding anything.

Coverage is measured on **branch**, not line. If you find the gate reading the line figure,
that is a bug to fix here.

## Files

- `tests/FileMutation.Api.Tests/` — new integration tests
- `.github/workflows/ci.yml` — raise threshold, publish the report artifact
- `README.md` — coverage summary

## Pre-mortem

**Most likely failure:** The coverlet collector silently produces an empty report, the gate reads 0 branches, and a threshold that should fail passes. Green CI attesting to nothing.

**Early signal:** A coverage file that exists but reports 0 total branches, or a gate that goes green when raised to a threshold the code cannot possibly meet.

**Kill criterion:** Before ratcheting to 80%, set the threshold to 100% once and confirm CI goes **red**. A gate never seen to fail is not known to work.

## Acceptance Criteria
- [ ] `WebApplicationFactory` integration test: upload → mutated content returned under the
      original filename
- [ ] Rejection paths asserted as `ProblemDetails`, not just status codes: oversized (413),
      wrong type (415), missing file (400)
- [ ] `Content-Disposition` asserted, including a non-ASCII filename case
- [ ] Deterministic `TimeProvider` and `IRandomSequenceGenerator` fakes so assertions are exact
- [ ] Branch coverage ≥80%; the gate fails the build below it
- [ ] `ReportGenerator` HTML report published as a CI artifact
- [ ] Verified the gate actually fails: lower the threshold test locally or drop a test and
      confirm CI goes red. An unverified gate is not a gate.

## Verify with

```bash
dotnet test --collect:"XPlat Code Coverage"
# confirm the branch figure, not the line figure, drives the gate
```

## Do not

- Do not include `benchmarks/` in the coverage run — it distorts both runtime and the figure.
- Do not chase the last few percent with tests that assert nothing meaningful.
